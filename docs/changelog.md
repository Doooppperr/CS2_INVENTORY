# 变更记录

## 1.0.1 - 2026-08-14

- 管理员“全部监控目标”增加“查看库存”，可直接打开任意目标的最新快照、七天历史和差异；全局查看时隐藏普通用户的“取消监控”操作。
- 原子发布切换版本后显式重启 Web 与 Worker，确保新代码立即生效。
- API、账号、监控、快照和后台查询时间统一输出为带 `+08:00` 的北京时间。
- 前端固定使用 `Asia/Shanghai` 渲染时间，不再跟随访问设备的本地时区。
- 监控 Worker 默认请求简体中文物品名称（`schinese`）。
- 优先采用 Steam 返回的本地化 `market_name`，仅在缺失时回退到英文哈希名称。
- 公开库存合并时保留官方中文名称，不改变资产去重、数量或覆盖逻辑。
- 对仅返回英文哈希名的隐藏物品，使用 Steam 官方物品类视图补全中文名并缓存映射。

## 1.0.0 - 2026-08-14

- 整理原始库存查询源码与测试，建立正式项目结构。
- 增加开放注册、账号登录、管理员整合视图和共享监控。
- 增加异步首次扫描、每日批次、维护只读、额度账本和七天快照。
- 将所有可靠资产合并为统一库存；用户界面不分类或标记内部保护状态。
- 增加 GitHub、systemd、服务器清理、原子发布和回滚流程。
