# 库存变化与每日看板

## 用户口径

- 已私密只来自供应商明确 PRIVATE 错误；网络失败、429、NO_ITEMS 不当成清空。
- 首次发现是平台首次观察，不是买入凭证；历史 assetid 再出现单列展示，不断言组件取出。
- 历史按 target_id + assetid 保存，独立于八天快照。目标删除会清理对应历史和日报。
- 日报日期 D 比较 D 与 D-1 的 R2 深度结果；不使用 R5 轻量结果代替，不跨日期找基线。
- 永久身份历史回填自仍保留的可信观察，未保留的早期库存不作推断。
- 公开库存物品字段不变；内部资产证据不输出到公开 API。

## 看板

入口 `/app/dashboard`，只读接口 `GET /api/dashboard`。

参数：date（北京日期，今天及前七天）、scope（mine / 管理员 all）、section（signals / reappeared / pending）、q、sort（accounts / increase / max / decrease）、direction（all / increase / decrease）、page、page_size（1–100）。

快捷条件 peers=1：min_accounts 默认 2、min_per_account 默认 1；single=1：min_single 默认 2；match=any 默认满足任一，可选 all。未勾选条件展示全部有效变化。

日报保存独立基线和账号级变化；重复任务幂等，原始快照清理不改变已计算日报。账号权限、到期冻结、汇总和详情使用相同过滤条件，接口 Cache-Control 为 no-store。

精确版本使用上游 market_hash_name / markethashname，不合并磨损、StatTrak 和纪念品。没有可靠市场名称、类别、身份或实时证据的记录列入待核实。勋章等根据上游 Type 排除，不能用 tradable=false 排除保护皮肤。

有效增加 = min(区间首次发现件数, max(0, 当前件数 - 基准件数 - 历史再次出现件数))。正式排行要求两端可比较且各资产为实时记录；减少与增加分别汇总。

## 数据质量

轻量仍发送 parse=1、try_first_seven_days_blocked_items=1、no_cache=1。no_cache 不等于上游绝无缓存，因此未提供实时证明的保护响应在看板中保守标为待核实；不取消库存中的保护物品显示。

Steam 官方分页成功、数量可核验、无错误且无未验证/缓存资产时才允许完整对比。历史回填不补造完整性证据。私密/失败不写空快照，原有有效结果保留，最近尝试与有效结果时间分别展示。

## Steam 专用代理

应用可设置 `CS2_STEAM_PROXY_URL=http://127.0.0.1:17890`，只代理 steamcommunity.com 与 api.steampowered.com；SteamWebAPI 仍走原路径。未配置时保持原行为。支持 HTTP CONNECT（Mihomo mixed-port 提供该协议）。

服务器独立服务 `cs2-steam-proxy`，配置 `/etc/cs2-steam-proxy/config.yaml`，状态 `/var/lib/cs2-steam-proxy`。仅本机代理及控制端口，不开启 TUN、不修改全机 DNS/路由，默认拒绝其他目标域名。配置、节点凭据、订阅链接和控制密钥不得提交 Git。

连通性与接口可用性分别验收：Steam 首页 200 不代表库存接口无 429。限流仍采用已有有界重试，并保留状态，不标成空库存。

## 发布与回滚

新增迁移 `20261019_10` 仅新增表。发布脚本停写、SQLite backup API 备份、迁移、初始化后执行 `python -m cs2_inventory.reporting_backfill`，再恢复服务。回填不调用上游 API，不删除/改写原始快照。

旧代码忽略新增表，默认使用 `deploy/rollback.sh PREVIOUS_RELEASE BACKUP --code-only`。数据库恢复必须另行显式选择，避免丢失发布后新增数据。关闭代理时删除 CS2_STEAM_PROXY_URL 配置并重启 CS2 Worker，再停 cs2-steam-proxy；不要触碰其他项目服务。

验证：`PYTHONPATH=src python -m unittest discover -s tests -v`、`ruff check .`、`node --check src/cs2_inventory/static/dashboard.js`；桌面及 390px 构造数据界面验收，迁移在生产数据库副本先演练。
