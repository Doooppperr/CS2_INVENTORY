# API 额度与容量

- Inventory 日限额 2,000、账期限额 10,000。
- 深度扫描基准为 7 次请求：normal 1、trading 3、mode1 1、parse1 2。
- 35 个目标每天一次按 31 天计算为 7,595 次；全部首次扫描再增加 245 次。35 是容量参考值，不是新增目标的硬上限。
- 应用账期工作预算为 9,000；每日 300 是控制台参考值，只统计使用量且允许超过。账期预算仍作为 Worker 的硬停止线，并为分页、重试和管理员任务保留 1,000 次。
- 管理员控制台始终显示“当前值/参考值”；目标数量和今日额度超过参考值后仍继续插入与扫描。
- Worker 同时扫描两个目标，全局限制为每分钟 18 次请求。
- Profile 仅在首次添加及七天后刷新昵称时调用，使用独立额度。
