# 变更记录

## 1.1.1 - 2026-08-29

- 落地页、未登录控制台和登录后控制台增加“跟随系统、浅色、深色”统一主题选择器，默认跟随操作系统并在浏览器中持久化。
- 增加首屏同步主题解析、系统主题实时监听及跨标签页同步；存储不可用或值异常时自动回退为跟随系统。
- 浅色模式保留现有米色暖橙复古外观；深色模式覆盖监控、详情、管理员、表格、状态、Toast 和弹窗，采用紫黑背景、霓虹紫强调及青绿色状态色。
- 控制台样式由旧深色基线叠加暖色覆盖，整理为单一结构样式与两套语义主题变量；用户账号、密码、权益、监控数据和业务 API 均未修改。

## 1.1.0 - 2026-08-28

- 调整监控列表备注操作列为固定宽度并居中按钮，移除右侧外边距造成的视觉左偏。
- 已登录落地页只保留一个“进入控制台”入口，移除首屏“获取套餐”按钮；修复库存详情返回生成 `/app/` 而触发 404，并兼容控制台尾斜杠地址。
- 落地页与控制台改用米色、暖橙和深色描边的复古界面；控制台增加“平台首页”入口。
- 管理员导航精简为概览、用户管理、全部监控目标三个板块，邀请码并入用户管理并与用户列表一同加载。
- 修复登录与注册复用表单时把注册密码最短 8 位规则错误应用到旧账号登录的问题；登录继续兼容原密码，注册仍要求 8-72 位。
- 新注册账号改为一次首次扫描体验；成功结果保留七天，空体验和结果到期账号自动删除。
- 增加月度、年度、永久一次性邀请码，支持自然月/年续期、七天冻结宽限和每用户监控限额。
- 全部升级前账号保留为内部永久无限权益；管理员可生成、撤销邀请码并调整正式客户限额。
- 监控关系增加用户私有备注，列表和详情使用个性化显示名。
- `/` 改为公开功能与套餐落地页，控制台迁移到 `/app`，联系方式为 `star0718@outlook.com`。
- 增加独立 15 分钟生命周期清理 timer、有效订阅每日扫描过滤、SQLite 一致性备份及数据库/units 完整回滚。

## 1.0.3 - 2026-08-20

- 唯一 SteamID 的 35 个容量限制改为控制台参考值，删除应用检查和 SQLite 容量触发器，允许继续新增。
- 每日 300 次工作额度改为只统计、可超过；账期预算仍保留 Worker 硬停止行为。
- 管理员概览明确标注目标数量和今日额度为可超过的参考值，API 同步返回是否执行限制。

## 1.0.2 - 2026-08-19

- 移除重复启动时恢复三个预置监控目标的行为，并一次性清理旧预置目标。
- 账号停用/恢复改为永久删除，共享目标保留，无主目标与历史自动清理。
- 管理员控制台拆分为概览、用户管理、全部目标三个子页面并按需加载。
- 普通与管理员列表页码写入 URL，详情返回和浏览器后退恢复原页。
- 三个分页接口自动规范化越界页码，删除末页数据后返回有效页。

- 最新库存按资产保留明确交易保护状态；同名保护物品与普通物品拆分计数，保护行使用金色样式置顶。

## 1.0.1 - 2026-08-14

- 项目开发与运维资料目录统一命名为 `开发文档/`，并增加文档索引与整理记录。
- 合并两份由主库存算法测试完整覆盖的旧测试文件，测试总数由含重复项的 67 项整理为 48 项独立测试。
- 管理员“全部监控目标”增加“查看库存”，可直接打开任意目标的最新快照、七天历史和差异；全局查看时隐藏普通用户的“取消监控”操作。
- 原子发布切换版本后显式重启 Web 与 Worker，确保新代码立即生效。
- API、账号、监控、快照和后台查询时间统一输出为带 `+08:00` 的北京时间。
- 前端固定使用 `Asia/Shanghai` 渲染时间，不再跟随访问设备的本地时区。
- 监控 Worker 默认请求简体中文物品名称（`schinese`）。
- 优先采用 Steam 返回的本地化 `market_name`，仅在缺失时回退到英文哈希名称。
- 公开库存合并时保留官方中文名称，不改变资产去重、数量或覆盖逻辑。
- 对仅返回英文哈希名的隐藏物品，使用 Steam 官方物品类视图补全中文名并缓存映射。
